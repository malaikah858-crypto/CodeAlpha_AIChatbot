# CodeAlpha AI Chatbot

A simple AI-style chatbot developed in Python as part of the CodeAlpha Python Programming Internship.

## Project Description

This project is an interactive chatbot that accepts user input and provides responses based on predefined conversational patterns.

The chatbot uses Python's regular expressions, string processing, conditional statements, functions, dictionaries, and random responses.

## Features

- Greeting responses
- Conversation handling
- Python-related responses
- Name and introduction response
- Thank-you responses
- Text cleaning using Regular Expressions
- Random response selection
- Unknown-question handling
- Exit command using "bye"

## Technologies Used

- Python
- VS Code
- Regular Expressions
- Random module

## How to Run

1. Open the project in VS Code.
2. Open `chatbot.py`.
3. Run the Python file.
4. Enter your message in the terminal.
5. Type `bye` to end the conversation.

## Example

```text
===================================
      CodeAlpha AI Chatbot
===================================
Hello! I am your AI chatbot.
You can ask me simple questions.
Type 'bye' to exit.

You: hello
Bot: Hello! How can I help you?

You: what is python
Bot: Python is a popular and beginner-friendly programming language.

You: bye
Bot: Goodbye! Have a great day!
